# English statistics: one poll of current values

*2026-11-21. Code: `english_stats.py` (`EnglishStats`, `ContextHash`); tests: `tests/test_english_stats.py` (7). No phonetics: this is "what number did they end up at" under the Scalar Context Propagation hash.*

* **One data class.** `EnglishStats` holds word counts, ordered-pair counts, context counts, the same keyed by each word's **context class** (the final number the hash lands on for its first WordNet sense, from `map/scalar_context_map.tsv.gz`), and the level cuts. `poll()` returns the current values as plain data. Statistics need not be live: `observe(text)` can be run any time and the object read when a pathway runs.
* **Prediction.** `P(w | prev) = a·P_word + b·P_class(class(w) | class(prev))·P(w | class(w)) + c·P_unigram`, each part a distribution over the vocabulary (the mixture sums to about 1, tested). Frequency is counted; the A-matrix cannot do that (it merges by max).
* **Granularity = the assumed educational response desire.** Levels `child / general / college / specialist` are vocabulary rank cuts (1,000 / 5,000 / 20,000 / all); a word beyond the level's cut loses its word-pair evidence and is spoken from its class. `level_for(text)` infers the level from the median frequency rank of the user's own content words. Class granularity is `class` (1,276), `basin` (15) or `word`.
* **Measured** (`Currentwork/Wernicke/corpus/stats_curve.txt`, same held-out text as the A-matrix curve): bits per held-out word fall as it is taught, **10.06 → 9.82 → 9.63 → 9.41** over four rounds (613,095 tokens), where the A-matrix field went 11.88 → 12.27. By level on the full training: child 9.70, general 9.49, college 9.41, specialist 9.41.
* **The context class does not help the prediction.** Without the hash the same object scores 9.34 after round 4; with it 9.41. Class 1 (`hypernyms=1`) holds about 31% of tokens, so the class part is nearly uninformative as a backoff. The classes are not wrong; they are too coarse to predict the next word. They remain the labels for where a word lives.
* Learning is from the user's text only (outside, echo 0); the window's own speech does not feed the counts.
