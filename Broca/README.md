# Broca: the scalar / scaled boxkite tree

Branch: `boxkite`. The structure side: the context kite, its struts and relations, the Mind's Eye kite in motion (De Marrais G2 deformations), context flow, and the morphology/conjugation `repass()` to come. It constrains and orders; it may extinguish a candidate but does not outvote the semantic web. (Broca's area: sequence and structure. An analogy used as a division of labour, not neuroscience.)

The scalar kite is the **discrete static** one (7 ordered pairs: pencil, string, flashlight, tension law). The scaled Mind's-Eye kite must **move**; never insert static functionality into it.

Copies only; the originals stay where they are in VAPMIP. Run Python files from the VAPMIP root, or with `PYTHONPATH=..`.
